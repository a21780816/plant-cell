# 介紹卡片引線與英文版 — 設計文件（簡短版）

- 日期：2026-11-18
- 狀態：使用者已同意（「可以，開始」）
- 前一份設計：`docs/superpowers/specs/2026-11-17-plant-cell-design.md`。本文件沒寫到的地方以它為準。
- 既有結構與行號的盤點：`.superpowers/sdd/recon-2026-11-18-callout-english.md`（不進版控）。

## 1. 要做什麼、為什麼

使用者看過成品後提出兩件事：

1. **引線**：選取胞器後出現的介紹卡片（`#panel`），要有一條線連到畫面上被選的那個胞器，像課本圖的標示線，讓人一眼看出這段介紹講的是哪一個。
2. **英文版**：整個成品能切成英文，包含介面、20 項構造的介紹、開場文字與測驗。

不做的事：第三種語言；依瀏覽器語言或網址自動選語言；另外打包一個英文檔；引線的遮擋判斷；改中文內容；改 3D 模型（Blender）。

做了就算失敗的事：中文版任何既有行為變差；英文內容與中文說的事實不一樣；引線蓋住介紹文字，或在不該出現時殘留在畫面上。

## 2. 做法的選擇

### 引線
- **A（採用）另加一層蓋滿視窗的 SVG**。卡片在畫布外（窄螢幕時在畫布下方）也連得到，與既有名稱標籤互不干擾。
- B 沿用名稱標籤的 `#labels` 圖層。不可行：那一層只有畫布大小、`overflow: hidden`，而且堆疊在卡片之下，窄螢幕時連不到卡片。
- C 在 3D 場景裡畫線。不採用：線寬會隨距離變、會被其他構造擋住，還要把卡片位置反投影回場景。

### 英文版
- **A（採用）同一個檔、執行時切換**。成品維持單一檔，兩種語言隨時可換。
- B 另外打包一個英文檔。不採用：要維護兩個約 6.6 MB 的檔，也不能中途切換。使用者之後若要單獨傳英文版給別人，可以再加「多輸出一個預設英文的檔」。
- C 中英並列顯示。不採用：卡片已經偏長，並列會更擠。

## 3. 引線的規格

- 元素：`<svg id="callout" aria-hidden="true">`，`position: fixed`、蓋滿視窗、`pointer-events: none`。堆疊在名稱標籤（`#labels`）之上，在清單、工具列、面板、測驗卡片之下。
- 內容：一條 `<line>` 加終點一個 `<circle>`。線寬、顏色、圓點大小比照名稱標籤的 `.leader` 與 `.anchor-dot`。
- 起點（在卡片邊緣）：
  - wide／short：x = 面板左緣；y = 標題色點（`#panel-dot`）中心的高度，夾在面板上下緣之內（面板內捲動時色點會移出去）。
  - narrow：y = 面板上緣；x = 色點中心的水平位置，夾在面板左右緣之內。
- 終點（在胞器上）：被選構造的目標點投影到螢幕，規則與鏡頭靠近用的目標（`main.js` 的 `targetOf`）一致：
  - 從清單或名稱標籤選取：`entry.anchor ?? entry.rep`。
  - 點選某一個體：該個體的根；它若就是代表個體，用 anchor。
  - 外殼類（`GHOST_IDS`）：一律 `entry.anchor ?? entry.rep`。
- 顯示條件，全部成立才顯示：phase 是 `explore`；有選取且面板顯示中；目標點在鏡頭前方；目標點在畫布範圍內（內縮 4px）；目標點不在面板矩形內；線長 ≥ 12px。
- 不做遮擋判斷：胞器被別的構造擋住時，線仍指向它的位置。
- 每格更新：鏡頭動畫、拖曳、縮放、拆解、自轉、視窗縮放都要跟上。幾何沒變就不寫 DOM。
- 取消選取、進入測驗、回到開場時隱藏。
- 幾何計算是純函式 `calloutGeometry(...)`，可單元測試。
- 除錯介面：`window.__cell.callout()` 回傳 `{ visible, x1, y1, x2, y2 }`，給端對端測試用。
- 名稱標籤同時開著時，兩者都顯示，不互相避讓。

## 4. 英文版的規格

### 4.1 語言狀態與切換
- `lang` 只有 `'zh'`（預設）與 `'en'`。放進 store，動作 `setLang(lang)`。所有文字都走既有的 `render(state)` 流程更新。
- 切換時不重新載入，階段、選取、拆解、名稱顯示、測驗進度都保留。
- 記住選擇：localStorage 鍵 `plant-cell-lang`。讀寫都包 try/catch，失敗就用預設。不看瀏覽器語言，不看網址。
- 切換鈕：兩個並排的按鈕「中文」「English」，文字固定、不隨語言變；目前語言的那個 `aria-pressed="true"`。出現在兩處：開場卡片上、工具列最後面。任何階段都能切。
- `<html lang>`：zh 為 `zh-Hant`，en 為 `en`。`<title>`：`植物細胞`／`Plant Cell`。
- 英文模式的面板：標題顯示英文名稱，副標（`#panel-en`）隱藏。清單、名稱標籤、滑過名稱、測驗題目都用英文名稱（`organelles.js` 既有的 `en` 欄位）。

### 4.2 介面文字定稿

| 中文 | English |
|---|---|
| 植物細胞（標題） | Plant Cell |
| 開始探索 | Start exploring |
| 載入中… | Loading… |
| 細胞構造 | Cell structures |
| 檢視工具（aria） | View tools |
| 測驗（按鈕與 aria） | Quiz |
| 拆解／組合 | Explode／Assemble |
| 顯示名稱／隱藏名稱 | Show names／Hide names |
| 關閉介紹（aria） | Close description |
| 你知道嗎 | Did you know? |
| 第 N 題／共 M 題 | Question N of M |
| 請點出：X | Find: X |
| 答對了！ | Correct! |
| 答錯了，你點的是X。發亮的才是Y。 | Not quite. You clicked X. The glowing one is Y. |
| 答對 s／t 題 | You got s out of t |
| 再玩一次 | Play again |
| 結束測驗 | End quiz |

`main.js` 的 `FALLBACK_TEXT` 與 `LOAD_FAIL_TEXT` 照中文原意翻譯，由實作計畫寫出定稿。這兩則出現時 store 可能還沒建立，語言直接讀 localStorage。

### 4.3 英文內容
- 新檔 `web/src/organelles.en.js`：`ORGANELLES_EN = { [id]: { tagline, body, fact } }` 與 `INTRO_EN = { title, paragraphs, start }`。`organelles.js` 的中文內容不改。
- 忠實翻譯現有中文：事實、數字、單位、程度都相同，不加新主張，也不刪內容。
- 名詞用大學英文教科書的標準用法，美式拼法；構造名稱與 `organelles.js` 的 `en` 欄位一致。
- 長度（字元數，含空白）：tagline 10–120、body 400–1200、fact 30–400。`INTRO_EN` 段數與中文相同，各段合計 ≤ 1100。
- `fact` 為 null 的條件與中文相同（只有 `smooth_er`）。
- 英文字串不得含中日韓文字與全形標點（`/[　-〿㐀-鿿＀-￯]/`）。
- 必含內容：液泡要保留「模型裡的液泡比實際小」的說明（`vacuole` 的 body＋fact 符合 `/scale|proportion/i`，body 符合 `/smaller|reduced|shrunk|scaled down/i`）。`INTRO_EN` 要提到 mesophyll、middle lamella、plasmodesmata、vacuole，以及 scale 或 proportion。

### 4.4 版面（英文字較長）
- 清單：wide 1280×800 不超過三列，名稱不截斷；保留帶變高後，本細胞的壁仍完整落在可用範圍內。
- 面板：介紹較長時在面板內捲動（既有行為），每一則都要捲得到底。可調的只有英文模式下面板內文的字級與行高（不小於 13px），以及 wide 版面的面板寬度（最多 380px）。1280×800 下量出 20 則裡有幾則需要捲動並回報，目標不超過 8 則。
- 名稱標籤：沿用既有的排版與捨棄規則。1280×800 一般狀態下，英文模式顯示的標籤數若比中文少 4 個以上，要調整並回報。
- 測驗：最長的英文答錯訊息在 short（900×420）與 narrow（390×800）不被裁切、不蓋工具列。
- 開場卡片：英文在 1280×800、900×420、390×800 都要看得到「Start exploring」與語言切換鈕；文字放不下時在卡片內捲動。
- 工具列加了切換鈕後，short 與 narrow 不得溢出畫面。

## 5. 測試與驗收
- 既有 83 項單元測試、43 項端對端測試全部維持通過。預設語言是中文，行為不變。屬性改名之類的機械性調整可以改既有斷言，但不得放寬。
- 新增單元測試：`calloutGeometry`；英文內容（4.3 的每一條）；介面文字表（每個鍵兩種語言都有、英文無中文字）。
- 新增端對端測試：
  - 引線：wide 與 narrow 的起點終點、旋轉後跟隨、取消選取後消失、測驗中不出現。
  - 語言：切到英文後各處文字、切回中文、重新整理後記住、切換時選取與拆解狀態保留、測驗進行中切換。
  - 英文版面：4.4 的每一條。
- 端對端測試之間不得互相污染語言設定。
- 效能：1280×800 選取狀態下的 fps 不低於既有門檻。
- 成品仍是單一檔 `dist/plant-cell.html`，離線可開，沒有外部請求。
- 英文內容要由沒參與翻譯的審查者逐則對照中文，逐句判讀語意，不是只掃關鍵字。

## 6. 留給實作者決定的
介面文字模組的內部結構、store 怎麼帶 `lang`、切換鈕的外觀細節、面板矩形的快取策略、`data-zh` 屬性要不要改名。

## 7. 建議的任務切分
1. 介紹卡片引線。
2. 英文內容檔與它的單元測試（只新增檔案，不碰介面）。
3. 語言機制與切換鈕（所有介面文字改走文字表，接上英文內容）。
4. 英文模式的版面調整、截圖檢查與 README 更新。

## 8. 計畫階段的補充決定（2026-11-18）

規劃者對照程式碼後提出、主持人裁定。與前面各節有出入時以這一節為準。

- 第 3 節終點：點到代表個體時引線指向錨點，與鏡頭靠近用的 `targetOf`（指向個體根）不同。引線另寫 `calloutTargetOf`，鏡頭行為不改。
- 第 3 節「回到開場時隱藏」：成品沒有回到開場的路徑，以「phase 不是 `explore` 就隱藏」實作。
- 第 3 節「自轉時跟著動」：有選取時本來就不會自轉，這個情況不會發生。
- 第 3 節堆疊：`#callout` 用 z-index 1，DOM 順序放在 `#labels` 之後。
- 第 3 節圓點：填色用該構造的主色（與面板色點同色），線的顏色與寬度比照 `.leader`。
- 第 4.1 節 `setLang(lang)`：以動作物件 `{ type: 'setLang', lang }` 表達，開場階段也接受。
- 第 4.2 節：兩則錯誤說明的英文定稿見實作計畫的文字表。
- 第 4.4 節開場卡片：只有段落（`.intro-body`）在卡片內捲動，標題、開始鈕、切換鈕一直看得到。這個結構中英都套用。
- 第 4.4 節面板：寬度上限 380px 只套在英文模式。「需要捲動不超過 8 則」寫成測試斷言，調不過就停下回報，不放寬。
- 第 4.4 節名稱標籤：要調整時只能調英文模式的藥丸字級（不小於 12px）與左右內距（不小於 7px）。
- 第 5 節效能：以 fps ≥ 50 寫成斷言（上一份計畫的門檻）。
- 第 6 節：`data-zh` 改名 `data-name`，值跟著目前語言。
- 任務切分：「語言機制與切換鈕」拆成「文字表與語言狀態」與「介面接線與語言切換鈕」，共 5 個任務。
