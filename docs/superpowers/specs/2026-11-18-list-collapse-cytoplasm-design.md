# 構造清單收合與細胞質的選取呈現 — 設計文件（簡短版）

- 日期：2026-11-18
- 狀態：使用者已同意（「對，照這樣做」）
- 前兩份設計：`2026-11-17-plant-cell-design.md`、`2026-11-18-callout-english-design.md`。本文件沒寫到的地方以它們為準。

## 1. 要做什麼、為什麼

使用者看了成品後提出兩件事：

1. **底部的「細胞構造」清單要能收起來。** 想把清單收掉、讓畫面更乾淨時，目前沒有辦法。
2. **選「細胞質」時看不出它在哪裡。** 實際重現：選取後其他構造全部褪成米色；細胞質本身是一片不透明度 12% 的淡米色，只微微變亮，畫面上沒有東西亮起來。清單裡它的色點幾乎是白的，選取後的外框也是米色，在白底上都不明顯。

原因：細胞質不是一個有形狀的東西，而是填滿細胞膜以內、各構造之間的那一整片。現在的發亮方式是為有形狀的胞器設計的。

不做的事：把細胞質從清單拿掉；改其他外殼類構造（細胞壁、細胞膜、中膠層）的選取呈現；改細胞質的介紹文字；改 3D 模型（Blender）；窄螢幕的清單收合；記住收合狀態。

做了就算失敗的事：清單展開時的版面與取景和現在不一樣；選取細胞質以外的構造時，發亮與褪色的行為改變；英文模式漏掉新文字。

## 2. 做法的選擇

### 清單收合
- **A（採用）清單自己帶一個收合鈕。** 收起來後只留一條很矮的標題列，點同一顆鈕再展開。位置不變，容易找回來。
- B 把開關放進左上的工具列。不採用：工具列在窄視窗已經很擠，而且開關離它控制的東西太遠。
- C 清單改成滑鼠靠近底部才出現。不採用：觸控裝置沒有滑鼠，第一次看的人也找不到。

### 細胞質
- **A（採用）選取時把細胞質那一片明顯上色，其他構造不褪色。** 其他構造本來就泡在細胞質裡，一起留著顏色才看得出「這整片都是」。
- B 維持現在的做法，只把發亮調強。不採用：一片 12% 不透明的淡色再怎麼調亮，在褪色後的米色畫面上還是看不出來。
- C 從清單拿掉細胞質。不採用：細胞質是基本名詞，介紹裡還講了細胞質液與細胞質環流。使用者也選了不拿掉。

## 3. 清單收合的規格

- 適用版面：wide 與 short。narrow 不提供（清單本來就在畫布下方，不會擋到模型），收合鈕在 narrow 不顯示，清單一律展開。
- 收合鈕：`#list-wrap` 標題列裡的一顆按鈕 `#list-toggle`，在標題「細胞構造」的右邊。`aria-expanded` 反映目前狀態，`aria-controls="list"`。圖示用向下、向上的箭頭表示收合與展開，另有文字標籤給輔助科技：
  - 中文：「收起構造清單」「展開構造清單」
  - 英文：「Collapse structure list」「Expand structure list」
- 收合後：`#list`（20 顆按鈕）不顯示，`#list-wrap` 只剩標題列（標題加收合鈕），高度不超過 44px，水平位置不變。
- 取景：收合後底部保留帶跟著變矮，模型的可用範圍往下延伸，細胞因此變大；展開後回到原本的數值。兩個方向都是平滑過去，不是一格跳動。展開狀態下，1280×800 中文的可用範圍仍是 `{0, 16, 1280, 674}`、預設鏡頭距離仍是 22.17。
- 狀態：放進 store（`listCollapsed`，預設 false），動作 `toggleList`。不記到 localStorage，每次開啟都是展開的。
- 測驗：測驗時清單本來就整個隱藏。結束測驗後回到進入測驗前的收合狀態。
- 收合時，選取中的構造、拆解、名稱顯示、語言都不受影響；名稱標籤可以使用清單讓出來的空間。
- 鍵盤：收合鈕可以用 Tab 到達、用 Enter 或空白鍵操作；操作後焦點留在收合鈕上。
- 切換語言時，收合鈕的文字標籤跟著換。

## 4. 細胞質選取呈現的規格

只在 `selected.id === 'cytoplasm'` 時生效；其他構造的選取行為完全不變。

- **其他構造不褪色。** 選取細胞質時，所有其他構造的材質顏色與不透明度，和「沒有選取任何東西」時相同。
- **細胞質明顯上色。** 細胞質的網格改用醒目的顏色與較高的不透明度，並保留既有的呼吸式明暗變化。起始值：顏色 `#E8B95A`、不透明度 0.38、自發光強度 0.25。實作者另外各拍一張候選值的截圖（同色、不透明度 0.5；顏色 `#8FC3E8`、不透明度 0.35），由主持人看圖定案。定案值放在 `web/src/config.js` 的常數裡，測試讀同一個常數。
- 取消選取或改選別的構造後，細胞質回到原本的顏色與不透明度（12%）。
- 拆解狀態下選取細胞質，同樣上色。
- 鏡頭、引線、介紹卡片的行為不變（選外殼類本來就回到預設取景）。
- 已知的簡化：細胞質的網格是整個細胞內部的一塊，上色時液泡所在的位置也會被染到。實際上液泡內部不是細胞質。這一輪不處理。

清單的可見度（所有構造一起改，中英都套用）：

- 色點加一圈細的深色描邊：`box-shadow: inset 0 0 0 1px rgba(52, 48, 42, 0.28)`。淺色的色點（細胞質、液泡、細胞膜）在白底上才看得到。
- 選取中的按鈕在既有的構造色外框之外，再加一圈深色外環：`box-shadow: 0 0 0 1.5px rgba(52, 48, 42, 0.45)`。既有的外框顏色與粗體不變。

## 5. 測試與驗收

- 既有測試（單元 118 項、端對端 74 項）全部維持通過。介面文字表多了兩個鍵，檢查鍵數的既有斷言可以跟著改數字，其他斷言不得放寬。
- 新增單元測試：store 的 `listCollapsed` 與 `toggleList`（各階段都有效、只改這一個欄位、其他動作不改它）；文字表新增的兩個鍵中英都有。
- 新增端對端測試：
  - 收合：1280×800 與 900×420 按收合鈕後，`#list` 不可見、`#list-wrap` 高度 ≤ 44、可用範圍的下緣變大、本細胞的壁仍在可用範圍內、鏡頭距離變小；再按一次，可用範圍與鏡頭距離回到原值。取景變化是平滑的（逐格取樣，相鄰兩格的平移變化 ≤ 6px）。
  - 測驗前後保留收合狀態；390×800 沒有收合鈕且清單可見；英文模式的文字標籤；`aria-expanded`；鍵盤操作後焦點留在收合鈕。
  - 細胞質：選取後其他構造的材質狀態與未選取時相同（抽查細胞核、葉綠體、粒線體）；細胞質的顏色與不透明度等於定案的常數；改選細胞核後細胞質回到 12%、其他構造照常褪色；拆解狀態下也上色。
  - 清單：色點與選取中按鈕的 `box-shadow` 等於第 4 節的值。
- 截圖：選取細胞質（三個候選值各一張）、清單收合的 wide 與 short、英文模式各一張，存到 `assets/preview/`。
- 成品仍是單一檔 `dist/plant-cell.html`，離線可開，沒有外部請求。

## 6. 留給實作者決定的

收合鈕的外觀細節（大小、箭頭畫法）；`listCollapsed` 在 store 以外要不要另外寫到 `body` 的屬性供 CSS 使用；細胞質上色是改既有的 highlight 流程還是另開一條分支；常數的命名。

## 7. 建議的任務切分

1. 構造清單可收合（store、清單、版面計算、樣式、文字表、測試）。
2. 細胞質的選取呈現與清單可見度（highlight、config、樣式、測試、截圖）。
